## How we build

- **Real problem first.** Every tool here started as something that wasted our own time.
- **Safe by default.** Read-only unless you say otherwise; no stored secrets; risky actions ask first.
- **Easy to check.** Clear READMEs, documented limits, and honest notes on what is and isn't done yet.

## Get involved

Found a bug or have an idea? Open an issue on the project. Open Pajak already has outside contributors, and focused pull requests are welcome everywhere.
