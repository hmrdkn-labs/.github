# hmrdkn-labs

Where my tools live once they're useful to someone besides me. By [Dika](https://github.com/hamardikan).

- [Open Pajak](https://github.com/hmrdkn-labs/open-pajak): Indonesian tax calculator that shows every step. [Use it](https://openpajak.hamardikan.com).
- [Agent Awake](https://github.com/hmrdkn-labs/agent-awake): keeps a Mac awake while coding agents work.
- [LazySS](https://github.com/hmrdkn-labs/lazyss): one terminal for SSH and AWS SSM. `brew install hmrdkn-labs/tap/lazyss`
- [Pak Satpam](https://github.com/hmrdkn-labs/pos-satpam): lets AI agents read monitoring and CI, safely.
- [DevOps, process to pod](https://github.com/hmrdkn-labs/devops): a free course from Linux to Kubernetes. [Read it](https://devops.hamardikan.com).

Issues and pull requests welcome.
