## Engineering approach

- **Solve a concrete problem.** Explain the use case before the stack.
- **Make behavior inspectable.** Document interfaces, boundaries, and failure paths.
- **Keep changes deliberate.** Prefer explicit approval for write-capable operations and clear limits on credentials and data.
- **Be honest about status.** Each repository documents its own setup, limitations, and release state; a public source tree is not proof of production deployment.
